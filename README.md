# Simple Dashboard

* 총 학습 가긴: 6~7회차(Lesson 회당 50분)
* 학습 목표:
  * lv1: Chart.js를 활용하여 차트 컴포넌트를 만들 수 있습니다.
  * lv2: Chart.js없이 svg로 직접 도표를 그릴 수 있습니다.
* 학습 방식:
  * 매주 과제가 있고, 수강생이 과제를 수행하고 PR을 생성하여 코드를 제출합니다.
  * 수업시간에 과제 결과물을 확인하며 코드리뷰 및 개념을 제대로 알고 있는지 체크합니다.
